# whatsapp-sender
Send multiple WhatsApp messages using a template.

![Screenshot](screenshot.png)

## Features
- Upload Excel/CSV/TXT file with a list of phone numbers (and names)
- Create a template (such as `Hello {name}`)
- Optionally add an international prefix to all numbers if they don't have it

## Install and run
- Windows: double click `start_windows.bat`
- Linux and MacOS: run command `sh start_linux_or_macos.sh`

Thanks to [WhatsApp Web JS](https://github.com/wwebjs/whatsapp-web.js) project, used by this app for sending the messages.
